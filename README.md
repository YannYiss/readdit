# Readdit

This is a read-only Reddit client made with React and Redux.

## Technologies used:

* HTML5
* CSS3
* Bootstrap
* Javascript
* React
* Redux
* GIT
* Reddit API

## Description:

This is a read-only client where you have the ability to browse the hottest topics by categories or search for a topic in particular using the search bar.

As it is a read-only client, you can't favorite, give points to a post or create new posts.
